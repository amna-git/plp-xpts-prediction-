# plp-xpts-prediction-
Premier League xPTS Prediction using Machine Learning

📊 Features
- Data visualization (heatmaps, bar charts)
- Feature engineering (Goal Difference, xG metrics)
- Random Forest model for prediction
- Model evaluation (MAE, RMSE, R²)
- Feature importance analysis

🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib & Seaborn

📂 Dataset
The dataset includes:
- Goals scored (GF)
- Goals conceded (GA)
- Expected Goals (xG)
- Big chances
- Possession stats

```bash
pip install -r requirements.txt
